1. Load your transaction files

This browser's data — transactions, ledger entries, income sources, categories, tiers, groups, keyword rules, and flags — lives only on this device/browser. Export a backup regularly, especially before switching browsers/computers or if things stop saving. Import loads a backup back in (replaces current data in this browser).

2. Income sources

A source with a future start date is listed but excluded from every income total and gauge until that date arrives.

3. Checkbook ledger — manual entries

4. Keyword auto-categorization rules

New CSV uploads auto-assign a category to anything that arrives "Uncategorized," by scanning its description for these keywords. If you also set an amount, the transaction's amount must match it (± a penny) for the rule to apply — leave it blank to match on keyword alone. Rules are checked in order — put more specific keywords first. Click "Apply Rules Now" to sweep every transaction and ledger entry (not just Uncategorized ones) and move anything matching a rule into that rule's category — this is how you reorganize things that are already categorized.

5. Master Entry List — all loaded transactions

Every transaction and ledger entry currently loaded into the app and feeding the dashboard above — in one place. Search, sort by any column, recategorize, flag for review, or permanently delete an entry. Deletions are remembered, so a deleted entry won't come back even if you re-upload the same file.

6. Possible duplicates — needs review

Entries with the exact same category and amount, on different dates. Confirm once whether it's a normal recurring item or an accidental duplicate — your answer is remembered for future uploads.

7. Flagged for review

Transactions you've manually flagged — e.g. multiple similar charges at the same place close together — so you and your family can double-check for errors or fraud before they get lost among everything else. Flag or unflag any transaction from its category's transaction list.

8. Category fuel gauges

On pace (<85%) Watch (85–100%) Over normal (>100%)

9. Classify categories, spending tiers & groups

Tag each category so gauges can be grouped by how essential the spending is. Critical Fixed = same amount every period, non-negotiable (mortgage, auto loan, allotments). Critical Variable = you must pay it, but the amount depends on usage (groceries, gas, utilities). Discretionary = controllable spending — the area to watch closest (shopping, dining, entertainment). Check Hide from dashboard for a category you're done tracking (e.g. a paid-off loan) — its gauge card disappears from section 8, but its transaction history, tier, and group stay intact and it can be unhidden any time.
